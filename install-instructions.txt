Como instalar o Ora

Abra https://oratime.com.br/manual-install.html no navegador em que você quer usar o Ora. O guia tem instruções para Chrome, Firefox, Edge e Brave e explica como verificar outros navegadores.

Depois de instalar pela loja, clique no botão + para abrir uma nova aba. Se o navegador pedir para confirmar a mudança, escolha Manter alterações ou a opção equivalente.

No Chrome, se a nova guia mostrar a barra com Personalizar o Chrome, você pode ocultá-la. Abra o painel, role até Rodapé e desligue Mostrar rodapé na página “Nova guia”. Veja as imagens em https://oratime.com.br/manual-install.html#chrome.

Se o Ora não abrir, procure a extensão na página de gerenciamento do navegador e confirme se ela está ativa. No Firefox, use about:addons. No Chrome, Edge e Brave, use chrome://extensions, edge://extensions ou brave://extensions.
